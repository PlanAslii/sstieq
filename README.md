# SSH VPN Panel v1.2.2

A colorful, English-language terminal panel for managing SSH accounts with Dropbear, Stunnel, Squid, and BadVPN UDPGW. The login banner can be customized independently through a Cloudflare Worker.

> **Important:** The Worker controls the SSH server's login banner only. It cannot change messages generated by a third-party SSH provider or by an Android injector app. SSH client logs often do not render ANSI colors, so the banner uses Unicode framing and emoji for a richer appearance while remaining plain text.

## Features

- Colorized installer and terminal menu (respects `NO_COLOR`).
- Create, delete, list, and extend SSH accounts.
- SQLite storage for accounts, settings, and connection history.
- PlanAsli-branded Cloudflare Worker login banner, preconfigured for the supplied Worker URL.
- Dropbear's `-b` banner option is explicitly configured and repaired automatically on panel startup.
- Automatic Dropbear compatibility for panel accounts using the non-interactive `/bin/false` shell.
- Automatic post-create SSH readiness check with an admin-facing repair/status message.
- In-panel password reset with a generated password (menu option 11).
- Dropbear SSH: `143, 444, 666, 5555, 701, 179`.
- Stunnel TLS: `110, 443, 587`.
- Squid proxy: `8080, 8000, 3128`.
- BadVPN UDPGW: `7300`.
- BBR tuning, UFW rules, expiration checks, and optional GitHub updater.

## Requirements

- Root access on a clean Ubuntu or Debian server.
- The installer accepts any Ubuntu release and Debian `11`, `12`, or `13`; package installation requires working APT sources that match the installed OS.
- At least 1 GB RAM and 10 GB disk space recommended.

Ubuntu `20.04`, `22.04`, `24.04`, and `26.04` are the installer's targeted releases. Other Ubuntu releases are attempted with a compatibility warning, but are not guaranteed; end-of-life releases may require archive repositories or Ubuntu Pro. The installer does not rewrite APT sources. Keep all enabled Ubuntu repositories on the same codename as `/etc/os-release`.

## Install

```bash
git clone https://github.com/PlanAslii/sstieq.git
cd sstieq
chmod +x install.sh
sudo ./install.sh
```

Open the panel after installation:

```bash
sudo sshvpn
```

## Customize the connection banner

The panel is preconfigured with `https://mute-bar-da37.planasli1.workers.dev/`. The suggested banner is branded **PlanAsli**.

To customize it, edit the `banner` constant in `worker/success-worker.js` and redeploy that Worker. On a fresh install, the installer fetches the banner automatically. On an existing server, open `sshvpn`, choose option **6**, and press Enter to fetch the current Worker message again. Keep the response as plain text—many SSH clients show it in their logs and may display ANSI color codes literally.

On install and at panel startup, the project ensures `/bin/false` is listed in `/etc/shells`, because Dropbear checks a user's configured shell before accepting authentication. The shell remains non-interactive. Use menu option **11** to generate and set a new account password without running shell commands manually.

## GitHub updates

The updater is preconfigured for `PlanAslii/sstieq`. The scheduled check runs daily at 03:00 server time; updates are copied into `/etc/ssh-vpn-panel`.

## Logs and configuration

- Panel database: `/etc/ssh-vpn-panel/db/users.db`
- Login banner: `/etc/ssh-vpn-panel/config/banner.txt`
- Logs: `/etc/ssh-vpn-panel/logs/`
- Main menu: `/etc/ssh-vpn-panel/scripts/menu.sh`
